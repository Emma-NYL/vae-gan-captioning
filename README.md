# VAE-GAN Captioning

## Overview

This project implements an image captioning system that combines deep visual feature extraction with sequence generation. It explores the use of a VAE-GAN-based fusion model to learn meaningful visual representations, which are then used to generate natural language descriptions for images.

The project demonstrates how computer vision and natural language processing can be integrated into a unified deep learning pipeline.

## Purpose

The goal of this project is to design and implement an end-to-end image captioning framework that can:

* Extract high-level visual features from images
* Learn robust representations using VAE-GAN fusion
* Generate descriptive and coherent captions

This project was developed to strengthen practical skills in deep learning, model design, and machine learning system organization.

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Emma-NYL/vae-gan-captioning.git
cd vae-gan-captioning
```

### 2. Set up environment

```bash
python -m venv venv
source venv/bin/activate
```

For Windows:

```bash
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run prediction

```bash
python predict.py
```

### 5. Run evaluation

```bash
python eval_test.py
```
